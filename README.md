## 这个 Skill 能做什么

上传一张 JPEG 或 PNG 照片后，它会先理解画面的曝光、白平衡、色彩、层次、质感和视觉重点，再根据这张照片适合的发展方向完成调色。

它不是一组预设滤镜。不同照片会得到不同方案，例如自然还原、明亮商业、低饱和叙事、胶片氛围或电影感；只有真正适合当前画面的方向才会被采用。

- 修正曝光、白平衡、高光、阴影、黑白场和整体对比度
- 调整曲线、HSL、饱和度、色彩分离与三向色彩分级
- 根据画面结构进行局部明暗和色彩塑造
- 在有必要时进行克制的降噪、清晰度、纹理和锐化处理
- 输出全分辨率成片，并检查尺寸、透明通道、溢出、光晕、肤色和细节是否异常

## 它怎样完成一次调色

1. **分析原图**：结合画面观察与图像指标，判断问题、优势和可塑造的视觉重点。
2. **设计方向**：围绕当前照片提出真正有差异的调色方案，而不是只改变色温或饱和度。
3. **独立出片**：每个版本都从原图重新处理，不会在上一张成片上继续叠加调整。
4. **成片检查**：检查色彩、明暗、细节、边缘、渐变和输出文件，必要时自动调整后重新输出。
5. **交付与迭代**：直接展示可下载的成片；你可以选择其中一个继续修改。

## 使用方式

下载并安装 Skill 后，上传原始照片，直接描述你想要的结果即可。例如：

```text
给这张照片调色
```

```text
保留傍晚的暖色，但让人物更通透，给我几个不同方向
```

```text
只要自然耐看的版本，不要胶片感
```

```text
把第二张照片作为风格参考，只借鉴它的明暗、色彩和氛围来调整第一张
```

也可以显式指定：

```text
@python-photo-color-grade 调色
```

如果你没有指定风格，首轮通常会直接返回 3–6 张差异明确的成片，无需先回答一轮审美问卷。

### 选择风格和强度

每个方向使用字母区分，强度使用数字表示：

- `1`：轻度
- `2`：中等
- `3`：明显

例如，首轮可能得到：

```text
A3 自然通透
B3 明亮商业
C3 低饱和叙事
D3 电影氛围
```

之后你可以这样继续：

- `B`：选择 B，默认保持强度 3
- `D2`：把 D 调整为中等强度
- `AC2`：同时输出 A、C 的中等强度版本
- `B 再通透一点`：用自然语言继续微调 B
- `以 C 为基础提亮地面`：保留 C 的方向，只修改指定部分

后续只会重新输出你选中的版本。默认不展示复杂参数；如果你需要复现或研究，可以要求查看最终成片实际采用的设置。

## 这不是生成式修图

所有结果都来自原图已有像素的确定性调整。这个 Skill 不会生成、重绘或替换画面内容，也不会使用 AI 主体分割或天空分割来伪装成传统调色。

因此，它适合调色和质感塑造，但不适合以下任务：

- 移除或新增物体
- 磨皮、液化、改变五官或体型
- 内容感知修补、生成式扩图
- 替换天空、重绘景深或合成不存在的光影内容

这类需求应使用专门的生成式图片编辑或人像精修工具。

## 支持范围

- **输入格式**：JPEG、PNG
- **不支持**：HEIC、RAW
- **原图安全**：始终输出到新文件，不覆盖原图
- **输出方式**：默认保持原图格式与尺寸，并保留 PNG 透明通道
- **适用内容**：人像、风景、城市、静物、旅行、纪实等常见照片

如果文件格式不受支持、图片损坏或无法解码，Skill 会说明原因，而不是猜测性地生成结果。
