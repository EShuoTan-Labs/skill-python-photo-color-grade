<h1 align="center">Python Photo Color Grade</h1>

<p align="center">非生成式调色，让 AI agent 成为一名优秀的后期调色师</p>

## 这个 Skill 能做什么

上传照片，agent会提出多种适合该照片的审美方案（例如自然还原、明亮商业、低饱和叙事、胶片氛围或电影感），使用python代码完成调色。

- 修正曝光、白平衡、高光、阴影、黑白场和整体对比度
- 调整曲线、HSL、饱和度、色彩分离与三向色彩分级
- 根据画面结构进行局部明暗和色彩塑造
- 在有必要时进行克制的降噪、清晰度、纹理和锐化处理

## 它怎样完成一次调色

1. **分析原图**：利用python代码统计图像指标，结合画面观察，判断问题、优势和可塑造的视觉重点。
2. **设计方向**：围绕当前照片提出多种审美方向。
3. **独立出片**：对于每个方向，生成调色参数配方；把配方和原图传入python代码进行调色。
4. **成片检查**：检查色彩、明暗、细节、边缘、渐变和输出文件，必要时自动调整后重新输出。
5. **交付与迭代**：直接展示成片；你可以选择其中一个继续修改。

## 使用方式

上传原始照片，显式指定agent调用此skill即可：

```text
@python-photo-color-grade
```

如果你没有指定风格，通常会直接返回 3–6 张不同风格的成片

或者也可以描述你想要的结果：

```text
给这张照片调色
```

```text
保留傍晚的暖色，但让人物更通透，给我几个不同方向
```

```text
只要自然耐看的版本，不要胶片感
```

```text
把第二张照片作为风格参考，只借鉴它的明暗、色彩和氛围来调整第一张
```

### 选择风格和强度

使用字母表示风格：

- `A`：自然通透
- `B`：明亮商业

使用数字表示强度：

- `1`：轻度
- `2`：中等
- `3`：明显

例如，首轮可能得到：

```text
A3 自然通透
B3 明亮商业
C3 低饱和叙事
D3 电影氛围
```

之后你可以这样继续：

- `B`：选择 B，默认保持强度 3
- `D2`：把 D 调整为中等强度
- `AC2`：同时输出 A、C 的中等强度版本
- `B 再通透一点`：用自然语言继续微调 B
- `以 C 为基础提亮地面`：保留 C 的方向，只修改指定部分

后续只会重新输出你选中的版本。默认不展示复杂参数；如果你需要复现或研究，可以要求查看最终成片实际采用的设置。

## 这不是生成式修图

所有输出图片由python代码计算而来，AIGC含量为0。这个 Skill 不会生成、重绘画面内容。

因此，它适合调色和质感塑造，但**不适合**以下任务：

- 移除或新增物体
- 磨皮、液化、改变五官或体型
- 内容感知修补、生成式扩图
- 替换天空、重绘景深或合成不存在的光影内容

这类需求应使用专门的生成式图片AI。

## 支持范围

- **输入格式**：JPEG、PNG
- **不支持**：HEIC、RAW
- **原图安全**：始终输出到新文件，不覆盖原图
- **输出方式**：默认保持原图格式与尺寸，并保留 PNG 透明通道
- **适用内容**：人像、风景、城市、静物、旅行、纪实等常见照片

如果文件格式不受支持、图片损坏或无法解码，Skill 会说明原因，而不是猜测性地生成结果。

## Skill 工具箱

agent 可以通过下面这些能力组合成一套完整的调色方案。以下能力由python代码提供

| 工具类别 | 可以调整的内容 |
|---|---|
| 指标统计 | 读取格式、尺寸、位深、透明通道和 ICC 状态，并统计亮度分布、阴影与高光溢出、RGB 通道、饱和度及画面不同区域的明暗和色彩信息，为调色配方提供依据 |
| 基础明暗与白平衡 | 色温、色调、曝光、高光、阴影、白色色阶、黑色色阶、对比度 |
| 整体色彩 | 自然饱和度、全局饱和度 |
| 曲线 | 整体明度曲线，以及红、绿、蓝三个通道的独立曲线；可塑造黑位、中间调、高光、褪色感和通道色彩倾向 |
| HSL 分色 | 分别调整红、橙、黄、绿、青、蓝、紫、洋红的色相、饱和度和明度 |
| 三向色彩分级 | 分别为阴影、中间调和高光设定色彩，并调整明暗区域的平衡与过渡融合 |
| 空气感与层次 | 去雾、清晰度、纹理；分别作用于大尺度雾感、中尺度局部对比和细节质感 |
| 蒙版与局部调整 | 支持明度范围、颜色范围、线性渐变、径向渐变及可嵌套的交集、并集和相减组合蒙版；可设置强度、反选及相应的羽化或平滑过渡，并在蒙版内局部调整色温、色调、曝光、高光、阴影、白色、黑色、对比度、自然饱和度、饱和度、明度及 RGB 曲线、清晰度和纹理。蒙版依据像素明度、颜色和几何位置计算，不是 AI 语义蒙版 |
| 细节处理 | 克制降噪、锐化、锐化半径、噪点阈值保护和强边缘保护 |
| 色彩与渐变保护 | 感知色彩处理、柔和色域压缩、16 位 PNG 输出，以及用于缓解 8 位 PNG 渐变色带的抖动 |
| 输出控制 | JPEG 质量、PNG 压缩等级、PNG 8/16 位深度，并保留原图尺寸和 PNG 透明通道 |
